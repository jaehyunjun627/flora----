### 1. API 호출 일관성 부족 ⭐⭐⭐

**문제:**
```javascript
// ✅ API 모듈 정의됨
import { orderApi } from '@/api/orderApi.js';

// ❌ 하지만 실제 사용은 직접 호출
fetch('/api/orders', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify(orderData)
});

// ✅ 올바른 방식
const order = await orderApi.createOrder(orderData);
```

**해결 방안:**
```javascript
// api/orderApi.js - 정의되었으나 사용 안 됨
export const orderApi = {
  // GET /api/orders
  getMyOrders: () => apiClient.get('/orders'),
  
  // GET /api/orders/:id
  getOrder: (orderId) => apiClient.get(`/orders/${orderId}`),
  
  // POST /api/orders
  createOrder: (orderData) => apiClient.post('/orders', orderData),
  
  // PATCH /api/orders/:id/cancel
  cancelOrder: (orderId) => apiClient.patch(`/orders/${orderId}/cancel`),
};

// 페이지에서 사용
import { orderApi } from '@/api/orderApi.js';

async function placeOrder() {
  try {

    console.log('주문 성공:', result.data);
  } catch (error) {
    console.error('주문 실패:', error);
  }
}
```

**효과:**
- ✅ 모든 API 호출이 한 곳에서 관리됨

### 2. 에러 처리 강화 ⭐⭐⭐

**현재:**
```javascript
// api/authApi.js (현재 상태)
const reponse = await apiClient.post('/auth/login', credentials);
// 401 에러 자동으로 처리됨

// 하지만 다른 에러는 각 페이지에서 처리
try {
  const result = await productApi.createProduct(data);
} catch (error) {
  alert('상품 등록 실패');  // 너무 일반적
}
```

**개선 후:**
```javascript
// api/index.js - 통일된 에러 처리
const apiClient = axios.create({
  baseURL: 'http://localhost:8080/api'
});

apiClient.interceptors.response.use(
  response => {
    // 백엔드에서 ApiResponse로 감싸진 응답
    const { success, message, data, error } = response.data;
    
    if (!success) {
      const errorMessage = message || error || '알 수 없는 오류';
      throw new Error(errorMessage);
    }
    return data;  // data만 반환 (프론트에선 깔끔한 데이터만 사용)
  },
  error => {
    // HTTP 에러 처리
    const status = error.response?.status;
    const message = error.response?.data?.message || '서버 오류가 발생했습니다';
    
    switch (status) {
      case 400:
        console.warn('입력값 검증 오류:', message);
        break;
      case 401:
        console.warn('인증 오류:', message);
        // 로그인 페이지로 리다이렉트
        window.location.href = '/login';
        break;
      case 403:
        console.warn('권한 오류:', message);
        break;
      case 404:
        console.warn('리소스 없음:', message);
        break;
      case 409:
        console.warn('중복:', message);
        break;
      case 500:
        console.error('서버 오류:', message);
        break;
    }
    
    return Promise.reject(new Error(message));
  }
);

// 페이지에서 사용 (간단함!)
async function createProduct() {
  try {
    const product = await productApi.createProduct(formData);
    showToast('상품이 등록되었습니다');
  } catch (error) {
    showToast(`오류: ${error.message}`);
  }
}
```

**효과:**
- ✅ 모든 에러를 일관되게 처리
- ✅ 상태 코드별 자동 처리
- ✅ 401 에러 시 자동 로그인 페이지 리다이렉트
- ✅ 페이지별 보일러플레이트 코드 제거

**개선: Zustand 상태 관리 도입 (간단함)**

설치:
```bash
npm install zustand
```

상태 관리 스토어:
```javascript
// stores/productStore.js
import { create } from 'zustand';

export const useProductStore = create((set) => ({
  products: [],
  loading: false,
  error: null,
  
  fetchProducts: async (page = 0, size = 12, category = '') => {
    set({ loading: true, error: null });
    try {
      const data = await productApi.getProducts(page, size, category);
      set({ products: data, loading: false });
    } catch (error) {
      set({ error: error.message, loading: false });
    }
  },
}));

// stores/cartStore.js
export const useCartStore = create((set) => ({
  items: [],
  
  addItem: async (productId, quantity) => {
    const response = await cartApi.addToCart({ productId, quantity });
    set(state => ({
      items: [...state.items, response.data]
    }));
  },
  
  removeItem: (itemId) => {
    set(state => ({
      items: state.items.filter(item => item.id !== itemId)
    }));
  },
}));
```

### 4. TypeScript 타입 정의 추가

**현재 (JavaScript):**
```javascript
// api/productApi.js
export const productApi = {
  getProducts: (page, size, category) => apiClient.get(...),
  createProduct: (data) => apiClient.post(...),
};
// 타입 정보 없음 → IDE 자동완성 불가
```

**개선 (TypeScript):**
```typescript
// api/types.ts
export interface Product {
  id: number;
  name: string;
  price: number;
  category: string;
  image: string;
}

export interface CreateProductRequest {
  name: string;
  price: number;
  category: string;
  description: string;
}

// api/productApi.ts
export const productApi = {
  getProducts: (page: number, size: number, category?: string) => 
    apiClient.get<Product[]>('/products'),
  
  createProduct: (data: CreateProductRequest) => 
    apiClient.post<Product>('/products', data),
};
```

**효과:**
- ✅ IDE 자동완성
- ✅ 타입 에러 미리 발견
- ✅ 코드 가독성 증가
